# Qualificação

Use quando faltarem informações necessárias para recomendar produto, calcular preço ou avançar o pedido.

## Regras

- Consulte o estado antes de perguntar.
- Pergunte somente informações ainda ausentes e necessárias para a próxima decisão.
- Se o cliente demonstrar desconhecimento de DTF, explique o mínimo necessário antes de pressionar fechamento.
- Prefira uma pergunta útil por vez a questionários longos.
- Não use qualificação como desculpa para adiar preço quando já houver dados suficientes para precificar.
